# 电路与接线

![接触检测电路图](images/maze-contact-circuit.png)

## 检测节点

```text
3V3 ── 10kΩ ──●── 绿线 ── D1 / GPIO3
               │
               └── 红线 ── 手持铁环

GND ─────────────── 黑线 ── 固定弯曲铁丝
```

铁环和铁丝相碰时，检测节点连接 GND，GPIO3 变为低电平。
分开时，10kΩ 电阻把检测节点上拉至 3.3V。
接触时通过电阻的电流约为 `3.3V / 10kΩ = 0.33mA`。

红黑线在两个金属件之间交换也可工作，这里固定采用红线接铁环、黑线接铁丝的约定。

## 开发板方向

看开发板**元器件正面，有金属屏蔽罩的一面**，保持 USB-C 在上：

| 引脚 | 物理位置 |
| --- | --- |
| D1 / GPIO3 | 左侧从上数第 2 脚 |
| GND | 右侧从上数第 2 脚 |
| 3V3 | 右侧从上数第 3 脚 |

翻到背面时，左右会交换。以板上丝印为准。电路图是电气连接示意，图内引脚位置不代表实物排列。

## 面包板

1. 3V3 所在排连接 10kΩ 电阻的一端。
2. 电阻另一端插入一个空闲数字行，例如右半边第 23 排。
3. 红线和绿线也插入右半边同一个第 23 排。
4. 绿线另一端接 D1；红线另一端接铁环。
5. 黑线一端接 GND，另一端接固定铁丝。

常见面包板同一数字行中，a～e 相通、f～j 相通；中央沟槽两侧不相通，相邻数字行也不相通。外侧电源轨是另一组连接，不属于 f～j。

## 注意

- GPIO 为 3.3V 电平，不能直接输入 5V。
- 红线接电阻下端的检测节点，不能直接接 3V3。
- 本项目必须有外部 10kΩ 上拉；程序未启用内部上拉。
- 铁环、铁丝和导线的接触点应为裸露导电金属，固定牢固。
- 200ms 防抖只能过滤短暂断开，不能使涂层或松动的接点导通。
